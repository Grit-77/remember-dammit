# Keep the decision separate from implementation evidence

Proposed lesson from this synthetic scenario: a source saying “we switched providers” records a choice; it does not itself establish that the code, configuration or running service changed.

Related: [current decision](../Projects/Atlas/Decisions/Email-Provider.md), [source](../Sources/Atlas-Brief.md), [project questions](../Projects/Atlas/Overview.md#open-questions).

This is labeled as an inference awaiting admission, not silently promoted to a proven universal rule.

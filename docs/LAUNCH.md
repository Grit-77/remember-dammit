# Launch drafts and first-run experiment

**Owner-run plan; draft copy, not a record of publication or user adoption.**
Review the [claim receipts](../FACTS.md) before distributing a draft.

## Draft launch copy

**Remember, Dammit. — carry a decision into your next agent session.**

Remember, Dammit. is a local, source-linked memory CLI and MCP server. You
explicitly save a note or decision, then ask your agent to recall it and show
where it came from. The memory core needs no model API key; your AI client
continues to use its normal account. This is a **0.2.0a1 source alpha**.

Try one small memory experience: save a harmless project decision, read it
back, and explicitly recall it in a fresh session. Start with the
[agent installation prompt](AGENT-SETUP.md). For a synthetic engine walkthrough,
use the [runnable demo](../README.md#try-it-without-an-ai-client).

The project reports a private synthetic Codex CLI trial on Windows, macOS and
Linux dated 2026-10-10. Claude Code attempts were blocked by quota or
authentication before memory tool use; native Cursor and Antigravity acceptance
remains open. See the [bounded report](LIVE-ACCEPTANCE.md). Saving and recalling
are explicit actions; automatic lifecycle recall is outside this alpha.

If you try it, tell us where installation slowed you down and whether you used
memory again in a later session. The [first-run feedback form](https://github.com/Grit-77/remember-dammit/issues/new?template=first-run.yml)
accepts both successful attempts and blockers. Omit secrets and private vault
content.

## Owner distribution checklist

- Review the installed version, README, demo output and claim receipts together
  on the candidate revision. Keep native trial results dated and attributed.
- Follow the single agent installation prompt in a disposable workspace and
  vault. Confirm source-note and task readback; ask the optional advisor question
  after the first memory experience. Record any mismatch with the guide before
  distribution.
- Confirm the feedback form is available on the published repository branch
  before using its public link. Preview and adapt the draft for each destination.
- Invite people who already use an agent and want to carry a decision between
  sessions. The owner chooses destinations and sends invitations; this document
  does not authorize posts or messages.
- Invite feedback without requesting stars, rewards for engagement, or artificial
  activity. Do not describe invitations, clicks or demo runs as returning users.

## Proposed early-user experiment

**Goal, not an achieved count:** seek five voluntary first-run attempts over a
two-week window. Start with Codex CLI, where the bounded native trial provides
evidence; identify other clients as exploratory attempts. Record client, version,
OS and candidate revision so different installation paths stay distinguishable.

Use a disposable project and harmless content. After the guided source-note and
task readback, start a fresh session attached to the same project and vault.
Ask the agent to explicitly recall the task and its next action and inspect its
source. Supply the lookup topic, without pasting the saved answer. Record whether
the returned content matches the note; a configured server alone is not success.

Ask after the attempt:

1. Where did installation or approval first become unclear or stop?
2. Did the readback and fresh-session recall match what you saved?
3. Would carrying this decision forward help with your next actual task?

For volunteers who agree to a follow-up, ask once within a week whether they
returned to save or recall memory for an actual task, and what helped or stopped
them. Distinguish this self-report from a directly observed recall. No response
means unknown, not a successful return or a failure.

Keep a private, sanitized tally of invitations, opted-in attempts, first readbacks,
fresh-session recalls, follow-up responses and reported returns. State the
denominator for each result; separate guided attempts from unaided ones. Collect
friction and useful examples rather than raw vaults or transcripts. Fix the most
repeated installation blocker, then repeat the same experience on the new revision.
